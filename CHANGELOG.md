# Changelog

## [2.0.0] - 2026-10-26

Moving from 1.x versions to version 2.0.0 may cause formatting changes to objects and lines of code that contain binary operators.

### Added

- Enables `objectWrap` option set to `collapse`.
- Enables `experimentalOperatorPosition` option set to `start`.

## [1.1.0] - 2025-06-25

### Added

Enabled the check for ignore pragmas option that Prettier introduced in v3.6.0. See [Check Ignore Pragma](https://prettier.io/docs/options#check-ignore-pragma) for more information about this option.

## [1.0.0] - 2024-08-25

Initial release.
